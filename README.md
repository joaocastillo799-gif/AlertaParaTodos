# Alerta para Todos · Web / Desktop

Sitio web de **Alerta para Todos**, un sistema de alertas de emergencia accesible para personas con discapacidad auditiva, visual y adultos mayores. Está hecho con HTML, CSS y JavaScript a partir de los mockups de Figma (MW-01 a MW-07).

## Pantallas

| Código | Pantalla | Archivo |
|---|---|---|
| MW-01 | Inicio / Panel principal | index.html |
| MW-02 | Alerta activa | alerta-activa.html |
| MW-03 | Configuración de accesibilidad | accesibilidad.html |
| MW-04 | Solicitar ayuda | solicitar-ayuda.html |
| MW-05 | Historial de alertas | historial.html |
| MW-06 | Detalle de alerta histórica | detalle-alerta.html |
| MW-07 | Solicitud enviada | solicitud-enviada.html |

## Qué funciona

- Todos los botones y el menú llevan a su pantalla, igual que el prototipo de Figma.
- Los interruptores de accesibilidad se activan y desactivan, y las preferencias se guardan al pulsar "Guardar preferencias".
- Tamaño de texto y de botones con los botones + y −.
- "Probar" lee en voz alta o hace vibrar el dispositivo.
- En la alerta activa se puede escuchar la instrucción, repetir el paso, agrandar el texto y elegir el paso.
- En Solicitar ayuda se elige el tipo de asistencia y la confirmación muestra el tipo elegido.
- En el Historial se puede buscar y filtrar por tipo y estado.

## Cómo verlo

Abre `index.html` en el navegador. También se puede publicar gratis con GitHub Pages.

Guía de estilos: tipografía Inter, azul #1565C0, celeste #E3F2FD, rojo de emergencia #D32F2F, verde #2E7D32.
